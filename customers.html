Bookings

    Any referee can book and start them from their console. Azure's cost is running time and storing the recordings; servers are deleted once they're shut down and everything is saved, so they cost nothing between bookings.

    Spartan's events

    Synced from Spartan's race list every 6 hours, when someone opens the console. Referees book an event's cameras from 07:00 to 18:00 local time on its days; admins can book any time.

    Who's refereeing each event

    Each referee sees the events they're assigned to on their home page, with the way to book that event's cameras. Being assigned doesn't change who can book: any referee can book any event.

      Referees

      Who can sign in: each referee signs in with Microsoft using this exact address. They can book and use the servers, cameras and results. Admins don't need to be on this list.

        Admins

        Admins add and remove referees and other admins, and can stop the servers. They sign in with Microsoft using this exact address.
