Set up streaming

Two phones film the burpee zone. Each sends its picture to the judging laptop over Tailscale and to YouTube, each on its own connection. The laptop records both, runs the AI judge, and serves live view and replay to the laptop and an iPad. Allow about 20 minutes the first time and 5 minutes on the day.

What you need

  • A Windows laptop (the judging computer), plugged in.
  • Two phones, Android or iPhone, each on a tripod or stand, with a power bank. Both need mobile data or Wi-Fi.
  • An iPad for the referees (optional).
  • One free Tailscale account (a Google or Microsoft sign-in is fine). The laptop, phones and iPad all sign in to it.
  • A YouTube channel with live streaming switched on, and one stream key per camera (optional). A new channel can take 24 hours to be allowed to stream.
Phone 1 and Phone 2 → Tailscale → laptop (record, AI judge, review) → laptop screen and iPad
Phone 1 and Phone 2 → YouTube (direct from each phone, so it keeps going if the laptop has a problem)

1. The laptop

Once. About 5 minutes. The Receiver app does most of it.

  1. Download and run the HeadJudge Receiver (about 140 MB).
    Download for Windows
    Windows will say "Windows protected your PC", because the installer isn't signed with a paid certificate yet. Click More info, then Run anyway. If your browser asks whether to keep the file, choose Keep.
  2. Open the Receiver. Windows asks once to let phones connect: say Yes.
  3. Step 1 in the app: click "Install Tailscale", say Yes when Windows asks, then sign in in the browser window that opens. The step goes green and shows the account name: use that same account on every phone and the iPad.
  4. Set Cameras to 2 at the bottom if it shows a different number.
  5. Optional, YouTube: paste each camera's stream key into its card (YouTube Studio → Create → Go live → Stream). Use a different key for each camera.
The Receiver starts with Windows, keeps recording every camera (14 days by default), and logs when each camera connects or drops.

2. Each phone

Once per phone. About 5 minutes. Choose how the phone sends its video:

Android or iPhone. Free. Adds a small "TEST STREAM" watermark. Keeps a backup recording on the phone.

  1. Scan the "Set up each phone" code in the Receiver (step 3) with the phone's camera. It opens a page with the right store links for that phone.
  2. Install Tailscale, sign in with the same account as the laptop, allow the VPN, and check it says Connected. The phone then shows in the Receiver under step 3.
    Turn off any other VPN on the phone. Leave Tailscale on.
  3. Install Larix Broadcaster (free) and open it once, allowing the camera and microphone.
  4. Scan that camera's Larix code in the Receiver (Camera 1 for the first phone, Camera 2 for the second) with the phone's camera, and open the link in Larix.
  5. Tap Import when Larix asks. The connections are only added once you do. Larix is then set up: to the laptop over Tailscale, to YouTube if you added a key, 720p with 1-second keyframes, and a backup recording on the phone.
    Android: if the camera won't open the link, use Google Lens, or click Copy Larix link in the Receiver and send it to the phone.
  6. Switch the connection on: Larix → Settings → Connections, tick Camera 1 to laptop (or Camera 2), and Camera … to YouTube if you use it. Untick any older connections, so the phone only sends where it should.
If you add or change a YouTube key later, scan the Larix code again, tap Import and check the connections are ticked.

Android only. A small app that only films and streams: no watermark, no sign-in. Tries the same Wi-Fi first and Tailscale if that doesn't work. iPhones need Larix.

  1. Install Tailscale from the Play Store, sign in with the same account as the laptop, allow the VPN, and check it says Connected.
    Turn off any other VPN on the phone. Leave Tailscale on.
  2. Install HeadJudge Broadcaster.
    Get HeadJudge Broadcaster
    The phone will warn you, because the app isn't from the Play Store. Tap Settings, turn on Allow from this source, go back and tap Install. If Play Protect asks, tap Install anyway.
  3. Open it and tap Scan station QR code, then scan that camera's Spartans app code in the Receiver (switch the camera's card to the Spartans app tab).
  4. Optional: tick Also stream live to YouTube and paste that camera's stream key.
  5. Leave Quality on 720p unless the signal is weak, then tap Open the camera → GO LIVE.
The full Spartans app has the same camera station (Home → Camera station), but needs a referee sign-in. The Broadcaster is for phones that only film.

3. The iPad (optional)

Only if the referees want to watch and replay on an iPad as well as the laptop.

  1. Install Tailscale on the iPad and sign in with the same account.
  2. Scan the "Watch and review" code in the Receiver (step 4) with the iPad's camera. It opens the review page in Safari.
  3. Share → Add to Home Screen so it opens like an app.

The laptop opens the same page from Video review in the Receiver. Several devices can watch at once without affecting each other.

Where to put the cameras

The AI judge can follow several athletes in one picture. It needs to see each one's whole body, head to feet, including when they're lying flat, and without one athlete hiding another.

  • Line the athletes up side by side, facing the cameras' side of the zone, about 1.5 m apart.
  • Put each camera at a front corner, angled 30–45° to the row, 5–8 m away. Never straight along the row: from the end, athletes hide each other.
  • Raise the phones to 1.8–2.2 m on a tall tripod or stand, tilted down a little, so they see over the near athlete when everyone is lying flat.
  • Fit everyone in, nice and big. Every athlete's whole body in the picture, head to feet, with a little space around. A standing athlete should be at least a third of the picture's height: much smaller and the AI can lose them when they're lying down.
  • Keep the space between the cameras and the athletes clear. Judges and spectators stand behind or beside the cameras, not in front.
  • Avoid the sun behind the athletes. Backlit athletes become dark shapes. Put the sun behind or beside the cameras.
  • Two cameras, two angles. If one athlete hides another from camera 1, camera 2 usually still sees them. Each camera is judged and recorded on its own, so use both views in Review.
Check it on the day: open AI judge camera 1 and have everyone do one burpee together. Each athlete should get their own label and count. If one keeps disappearing when they lie down, raise the camera or move it a little further away.

4. Test it

  1. Put each phone on its stand in landscape, placed as in Where to put the cameras.
  2. Start both phones: press Larix's red button, or in the Spartans app tap Open the camera → GO LIVE.
  3. In the Receiver, both cameras show LIVE · Tailscale. If you added keys, check YouTube Studio shows both streams.
  4. Open Video review on the laptop (and the iPad if you set one up): both cameras play live.
  5. Tap Mark incident, wait 20 seconds, then on the Replay tab tap Last 30 s: both cameras replay together.
  6. Click "AI judge camera 1" (and 2), do a few burpees and check they're counted.

Review and protests

  • Mark incident (Live tab) saves the laptop's time with an optional note, such as the bib number. Everyone's marks appear on every device.
  • Replay: tap a mark's Replay in the Log, use Last 15 s / 30 s / 2 min, or type any time. Both cameras play in step. Step frame by frame, slow to ¼ speed, and save a clip of either camera.
  • Replay never interrupts live recording, the AI judge or YouTube: it's read from the recorded files.
  • Times are the laptop's clock. The stamped time can be about half a second behind the real moment (the delay from camera to laptop), and the same for both cameras.
  • The Log lists every mark and every camera connect or drop. Download it as a spreadsheet for the protest record.
  • Full recordings: Receiver → Open recordings, one file per camera per 10 minutes.

If something fails

One camera stops
The other keeps streaming, recording and judging. The review page shows NO SIGNAL on that camera and the Log records the time. Larix reconnects by itself when it can.
A phone's Wi-Fi drops
The phone moves to 4G and Tailscale follows it, so Larix reconnects within a few seconds. Leave mobile data on.
The laptop has a problem
YouTube keeps going (it's direct from each phone), and phones using Larix keep their own backup recording (Photos or the gallery).

Troubleshooting

Larix says "Can't connect to server", or the Spartans app can't connect
Almost always Tailscale: check it's on, signed in to the same account and Connected on the phone, and that the phone appears as online under step 3 in the Receiver. Turn off any other VPN.
Larix says "authentication failed" (NetStream.Publish.Unauthorized)
The phone reached the laptop but the laptop rejected it. Update the Receiver to the latest version (download it again above), then on the phone delete the old Camera … to laptop connection in Larix → Settings → Connections, scan the camera's Larix code again, tap Import and tick the new connection. Over Tailscale no password is needed. If the Receiver shows An older streaming server is running, click Remove old server first.
It works at home but not at the event
Some event Wi-Fi blocks VPNs like Tailscale. Switch the phones to 4G/5G, or turn on the laptop's mobile hotspot (Windows Settings → Network → Mobile hotspot) and join the phones to it.
The picture is jerky or blurry
Weak signal. Lower the bitrate in Larix → Settings → Video (or set Quality to 480p in the Spartans app), or move to a stronger signal. Streaming to YouTube as well doubles what each phone sends (about 7 Mbps), so on poor 4G leave YouTube off one camera.
The iPad page doesn't open
Check Tailscale is Connected on the iPad, and step 2 in the Receiver is green.
YouTube doesn't go live
Check the key, that each camera has its own key, and, with Larix, that you scanned the code again and tapped Import after adding it. A new channel can take up to 24 hours to be allowed to stream.
Still stuck
In the Receiver, open Server log and send a screenshot of it, with a photo of the phone's screen, to whoever set the event up.
