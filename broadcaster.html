HeadJudge Broadcaster

Film for the judges

This phone sends its picture to your HeadJudge server and, if you like, live to YouTube at the same time.

This needs the HeadJudge Broadcaster app on an Android phone. A web browser can't send video this way.

Get the Android app

YouTube optional

In YouTube Studio: Create → Go live → Stream, then copy the Stream key. It's kept only on this phone. Use a different key for each camera. The first time, YouTube can take up to 24 hours to allow live streaming on a channel.

Open YouTube Studio

Go live

Then tap GO LIVE. Keep the app open with the screen on while filming, with the phone in landscape, on a tripod if you can.
