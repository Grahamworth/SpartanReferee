Camera station

Film a burpee station with this phone. The picture goes to the judging computer and, if you like, live on YouTube at the same time, each on its own connection. No watermark.

Setting up cameras for an event? Read the setup guide (Larix and Tailscale, two cameras, iPad review).

The camera station needs the Spartans app on an Android phone. A web browser can't send video this way.

Get the Android app

On an iPhone, use Larix Broadcaster for now (scan the station's QR code on the judging computer's connection page).

Scan the station's Broadcaster QR code in the HeadJudge Receiver on the judging computer. On the same Wi-Fi (or its hotspot) the phone connects direct; anywhere else it uses Tailscale, which must be on and connected on this phone (same account as the judging computer).

No station set yet.

In YouTube Studio: Create → Go live → Stream, copy the Stream key. It's kept only on this phone. Use a different key for each station. The first time, YouTube can take up to 24 hours to allow live streaming on a channel.

Then tap GO LIVE. Keep the app open with the screen on while filming; the phone in landscape, on a tripod if you can.
